# React Hooks Playground

A small Vite + React project demonstrating the major React hooks with inline comments.

## Features
- `useState` — Counter example
- `useEffect` — Update document title on change
- `useRef` — Focus an input programmatically
- `useMemo` — Optimize an expensive calculation
- `useCallback` — Memoize callback functions
- `useContext` — Shared user context
- `useReducer` — Complex counter with actions
- Custom Hook `useFetch` — Fetch data from an API

## Install and run

```bash
# install dependencies
npm install

# start dev server
npm run dev

# build for production
npm run build

# preview production build
npm run preview
```

Open http://localhost:5173 in your browser (vite default).
